# Privacy

Prius Companion requires no account or backend. Vehicle data, trips, adapter settings, diagnostic scans and action logs stay on the device unless the user explicitly exports them.

VIN storage is opt-in. Exports redact VIN and device identifiers by default. The app does not request location, does not log location, rotates bounded production logs, and keeps raw OBD logging off by default. Users can delete all local application data from Settings. Uninstalling also removes app-private storage subject to platform backup behavior.

Bluetooth permissions are used only to discover/connect to nearby adapters. Local-network access is used only for a user-configured Wi-Fi ELM327 endpoint.
